===rules-heading===
## How to decide
===rules===
Answer affects only when a note states something that, if it is true, makes the objective or at least one acceptance criterion wrong, impossible, already done, or ambiguous, or that changes what the context tells the session to do. A note that is about the same area, or that confirms what the task already says, does not affect it. When you are unsure, answer unaffected: a wrong affects costs a refinement session and a challenge, and a wrong unaffected costs only a note the working session still reads in its own prompt.
