## Shell limits in this session
===statement===
Shell commands are restricted in this session. You start in the checkout, so never use `cd` or `git -C`. Only a short list of read-only commands is allowed, and anything else is refused without a prompt. A pipe or a chain runs only if every command in it is allowed, and `$(...)` is always refused. Search the checkout with `grep -rn <pattern> <path>`, `find <path> -name <glob>`, and `ls`, or with the Grep tool if this session lists one. Read files with the Read tool or `cat`. For history, `git log -p -- <path>` shows a file's changes, `git log -G<regex> --oneline` finds the commits that changed a matching line, and `git diff 4b825dc642cb6eb9a060e54bf8d69288fbee4904 <revision> -- <path>` prints a file as it stood at any revision. The checkout is a complete repository, so `git show <revision>:<path>` prints a file at any revision, `git grep <pattern> <revision>` searches a revision, `git blame <path>` shows who last changed each line, and `git ls-files` lists the files. If a command is refused, do not retry a variation of it: use what you can read, and say in your report what you could not check or search as a result.
