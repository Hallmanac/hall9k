===where-you-are===
## Where you are

You are in a checkout of this pull request's current head, detached with no local branch. It is a real checkout, a standalone clone, and you may build and run tests in it — the rest of this review depends on your doing so, and no other review session shares it while you are here, because the platform dispatches one persona's session at a time over this one checkout. What you may never do is change it: no commits, no pushes, nothing written into the pull request itself, and nothing posted to GitHub in any form. The findings you write go into a report a human reads and directs by hand. Git LFS files are not downloaded into this checkout: a path the project tracks with LFS holds its small pointer text instead of the real file, because the checkout is cut with no remote to fetch large files from. That is how the checkout is made, not a defect in the pull request, so do not report a broken or missing large asset as one.
