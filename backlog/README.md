**Dogfood-era archive.** These files predate the hall9k project's own move into its
platform-native project home (backlog 52). They stay here for their history — the objective and
acceptance criteria each numbered file's frontmatter carries, and the earlier-stage prose in the
`IDEA-` notes beside them — and `docs/scope.md` still points into them wherever a designed
but unbuilt item traces back to one. New work no longer starts here: capture it with
`h9k idea add` or `h9k task add`, which renders into the project home's `tasks/` and `ideas/`
directories the same way every other project's work does (backlog 48).
